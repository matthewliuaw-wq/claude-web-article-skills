# 文章导读模板

## 导读结构

每篇导读遵循以下固定结构（可根据文章类型微调）：

```
1. 导学概览（来源、导读目标）
2. 开篇类比（用日常经验帮助理解核心概念）
3. 核心内容总览表（表格形式，先给全局图）
4. 逐节展开（每个大节包含：核心观点 + 原文图片 + 思考提示）
5. 整体回顾（总结表或 ASCII 图）
6. 拓展思考（2-3 个开放性问题）
```

## 文章类型适配

### A 型：技术概念文章
- 开篇类比用日常经验（如"培养学徒"理解智能体框架）
- 用"信号 → 收益"格式总结每个场景
- 保留原文中的代码示例作为引用块
- 结尾数据表对比效果

**示例**：Harnessing Claude's Intelligence、Subagents in Claude Code

### B 型：人物故事文章
- 开头用引人入胜的方式引入（如"一个不会写代码的项目经理，6周后App上架了"）
- 用时间线梳理关键节点
- 提炼 3-4 个核心洞见
- 用引用块展示人物原话金句

**示例**：Respiro 的六周诞生记

### C 型：实践教程文章
- 开头用对比帮助理解（如"记事本 vs Keynote"理解 Markdown vs HTML）
- 用对比表格展示优劣
- 用例场景用"场景 → 你能得到什么 → 示例 prompt"格式
- 示例 prompt 保留英文，附中文场景说明

**示例**：HTML 的超凡效力

## 导读格式规范

### 图片引用
- 导读文件在 `文章导读/` 子目录中，图片用 `../images/` 相对路径

### 思考提示框
```markdown
> **思考**：[引导读者主动思考的问题]
```

### 关键洞察
```markdown
> **关键洞察**：[一句话核心观点]
```

### 代码示例引用
```markdown
> **示例 prompt**：
> ```
> [保留英文原文的 prompt]
> ```
```

### 拓展思考
```markdown
## 拓展思考

1. **[主题]**：[具体的思考问题]
2. **[主题]**：[具体的思考问题]
3. **[主题]**：[具体的思考问题]
```

## 导读质量自查清单

- [ ] 开篇有类比或引人入胜的引入
- [ ] 有总览表/全局图（先给框架再展开）
- [ ] 原文图片全部保留且路径正确（`../images/`）
- [ ] 至少 2 处思考提示框
- [ ] 结尾有拓展思考问题
- [ ] 中文表达自然流畅，无翻译腔
- [ ] 代码/prompt 示例保留英文原文
- [ ] 文章类型适配正确（A/B/C 型）
